# Kerv Product Matrix

This is a Svelte app using Svelte Material UI (SMUI) components to implement the Product Matrix form based on the provided flow chart.

## Setup

1. Place your company logo at `public/logo.png` (this will appear in the header).
2. Install dependencies:

```bash
cd /Users/grantgorton/Desktop/Projects/kerv-product-matrix
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open your browser at the URL shown in the terminal.
